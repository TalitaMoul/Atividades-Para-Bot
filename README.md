# Atividades de Treino em Python

A ideia consiste em documentar minhas atividades de treino em conceitos básicos de Python, onde posteriormente será desenvolvido
um Bot para o Discord. O Bot gera uma votação para os usuários escolherem a match de cinco jogadores contra outros cinco jogadores,
sendo possível escolher duas opções de enquete: Votação Anônima ou Convencional.
